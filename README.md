# عيادة الدكتور غيث التميمي

الموقع الرسمي لعيادة **الدكتور غيث التميمي** (**دكتوراه في أمراض الدم السريري**)، مصمم بواجهة عربية حديثة (`RTL`) وتجربة مستخدم سريعة لحجز المواعيد إلكترونياً، متابعة طابور المراجعين، وقراءة وتحليل فحوصات الدم الشاملة (**CBC**) باللغة العربية.

---

## المميزات الرئيسية

### 1. التبويبات العلوية
- **العيادة:**
  - شريط **نشرة الأخبار** المتحرك في أعلى الصفحة.
  - معرض صور وأخبار تفاعلي قابل للتقليب مع فتح نافذة منبثقة عند الضغط على أي بطاقة.
  - بطاقة معلومات الدكتور والشهادة، وروابط التواصل المباشر (**واتساب**، **فيسبوك**، **إنستجرام**، و**موقع العيادة على خرائط Google**).
- **عدد الزيارات:**
  - إحصائيات إجمالي الزيارات، زيارات اليوم، حجوزات اليوم، وإجمالي الحجوزات مع توزيع الزيارات اليومية.
- **اختبار CBC:**
  - دعم **الإدخال الفردي** (فحص مؤشر واحد أو عدة مؤشرات محددة) و**إدخال الكل** لكامل فحص الدم الشامل (`WBC`، `LYM%`، `MID%`، `GRAN%`، `RBC`، `HGB`، `HCT`، `MCV`، `MCH`، `MCHC`، `RDW_CV`، `RDW_SD`، `PLT` وغيرها).
  - تفسير طبي فوري باللغة العربية مع تمييز أنماط فقر الدم (مثل فقر الدم صغير الكريات لنقص الحديد مقابل كبير الكريات لنقص فيتامين `B12`)، وإمكانية الحجز المباشر مع إرفاق ملخص الفحص.
- **حول:**
  - معلومات المنصة وبيانات المصمم.

### 2. الشريط السفلي والتفاعل السريع
- **زر الحجز (في المنتصف بأسلوب تيك توك):** يفتح نافذة منبثقة لإدخال:
  - الاسم الثلاثي
  - رقم الهاتف
  - موعد الحجز (**اليوم بتاريخ اليوم** أو **تحديد موعد آخر**)
  - حالة المريض (اختيارية)
  - يعرض رسالة تأكيد فورية تتضمن **رقم الحجز التسلسلي** وتاريخ الموعد.
- **الحجوزات (الجهة اليمنى):**
  - يعرض **حجوزات اليوم تلقائياً** مع إمكانية التبديل لعرض كل الحجوزات.
  - بحث فوري بـ **اسم المريض** أو **رقم الحجز** أو **تاريخ الحجز**.
  - عند النقر على أي حجز يظهر سؤال التحقق «هل أنت الدكتور؟»، وعند إدخال كود الدكتور (`cbc2000`) يُفتح **بروفايل المريض الكامل** مع أزرار الاتصال والواتساب وتحديث حالة المراجعة.

## إدارة الصور والشعار والأخبار (`public/pic.js`)

1. ضع الصور داخل المجلد **`public/image_folder/`**.
2. عدّل ملف **`public/pic.js`**:
   - لتغيير **الشعار الدائري أعلى الصفحة**:
     ```js
     LOGO_URL: "./image_folder/logo.jpeg",
     ```
   - لإضافة صورة أو خبر جديد في **معرض العيادة ونشرة الأخبار**:
     ```js
     gallery: [
       {
         id: "pic-1",
         src: "./image_folder/1.jpeg",
         title: "عنوان الصورة",
         subtitle: "وصف مختصر (اختياري)",
         tag: "التصنيف",
         news: "نص الخبر الذي يظهر في شريط الأخبار أعلى الصفحة (اختياري)"
       }
     ]
     ```

## ربط قاعدة البيانات عبر Google Sheets و Apps Script (`code.gs`)

1. افتح جدول بيانات جديد في **Google Sheets**.
2. انتقل إلى **Extensions ← Apps Script**.
3. الصق محتوى ملف **`code.gs`** بالكامل واحفظ المشروع.
4. اختر الدالة **`setup`** من القائمة العلوية واضغط **Run** لمنح الصلاحيات وتنصيب الأوراق (`Bookings`، `Visits`، `Settings`) وتنسيقها تلقائياً.
5. اضغط **Deploy ← New deployment ← Web app**:
   - **Execute as:** `Me`
   - **Who has access:** `Anyone`
6. انسخ رابط الـ Web App وضعه في حقل **`APPS_SCRIPT_URL`** داخل ملف **`public/pic.js`**.
